# JPMorgan Chase Software Engineering Virtual Experience – Midas Core Project

This repository holds my **in‑progress work** toward completing the **JPMorgan Chase Software Engineering Virtual Experience (Midas Core)** on Forage — a job simulation designed to give practical backend development experience.
---

## 📌 About This Project

Through this experience, I will be working on building backend components for a simulated financial transaction system featuring:

- Kafka message ingestion
- Database persistence using H2 and Spring Data JPA
- External REST API integration
- RESTful endpoints for querying balance

This project mirrors tasks similar to what a backend engineer might encounter in enterprise systems.

## 🛠 Technologies Involved

- Java

- Apache Kafka
- H2 Database

- Maven
